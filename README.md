# GIST Warehouse Rota System

A fair distribution work rotation system for warehouse operations managing staff assignments across frozen, milk, twi, inbound, outbound, and marshaling tasks with constraint-based scheduling.

## Features

- Staff management with bulk import and training assignments
- Day-specific task requirements configuration
- Constraint-based rotation algorithm
- Weekly view with annual calendar
- Rest days, absence, and holiday management
- PDF export for display
- Manager duties scheduling
- Real-time collaboration
- Analytics and fairness tracking

## Tech Stack

- Next.js 15.5 (Page Router)
- TypeScript
- Supabase (Database, Auth, Storage)
- Tailwind CSS + shadcn/ui
- React Query
